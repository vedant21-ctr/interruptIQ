# Security Policy

## Supported Versions

Only the latest release (v1.x) receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please report vulnerabilities by opening a private GitHub issue or contacting the core maintainers directly at security@interrupt-iq.com. We endeavor to investigate and patch all reported vulnerabilities within 72 hours.
